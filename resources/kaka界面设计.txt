# 咔咔 · 界面设计规范（UI Spec）

基于你的选择汇总：
- 1B（深灰专业）
- 2A（硬朗直角）
- 3B（舒适密度）
- 4A（底部缩略图横条）
- 5B（右侧信息面板）
- 6C（智能适配）
- 7A（纯黑背景）
- 8C（仅角标，删除反馈）
- 9C（无反馈，跳过操作）
- 10B（顶部进度条）
- 11A（居中大弹窗）
- 12C（网格视图，导入列表）
- 13C（按拍摄时间排序）
- 14C（左侧底部，设置入口）
- 15A（点击输入框按新键）
- 16B（填充图标）
- 17B（直接打开上次工作区）


## 一、整体设计原则

### 1.1 色彩方案

背景色：#1a1a1a（深灰专业基底）
预览区背景：#0a0a0a（纯黑，突出照片）
顶部栏背景：#222222（略深于主背景）
右侧面板背景：#161616（略深于主背景）
缩略图区背景：#141414
状态栏背景：#121212

边框/分割线：#2e2e2e 至 #3a3a3a

主色（强调）：#ffb347（暖橙色，用于高亮、按钮、焦点）
删除色：#ff6b4a（红橙色，待删标记）
保留色：#4cdb8a（翠绿，保留标记）
文字主色：#e0e0e0
文字辅助：#9a9a9a
文字弱：#666666

### 1.2 圆角与边框

硬朗直角，无圆角。
边框为实线，1px。

### 1.3 字体与信息密度

舒适密度。
字号层级（均为 s=1.0 @ 100% DPI 基准值，按显示器 DPR 等比缩放）：
- 顶部栏软件名：20px / 700
- 文件夹路径：14px / 400
- 照片信息（EXIF）：13px / 400
- 状态栏：14px / 400
- 快捷键提示：13px / 400
- 按钮文字：15px / 600
- Toast 提示文字：14px / 500
- 模态框标题：20px / 700
- 模态框正文：14px / 400
- 辅助说明小字：12px / 400

字体：
- 首选（Windows 11 默认）：Segoe UI Variable
- 降级顺序（按优先级，仅当上一个字体在系统中不存在时使用）：
  1. Segoe UI Variable Display
  2. Segoe UI
  3. Microsoft YaHei UI（微软雅黑 UI，Win10 默认中文）
  4. Microsoft YaHei
  5. Arial（最后兜底）
- 行高：正文 1.4，标题 1.2

1.4 状态色（按钮/输入框的悬停/按下/禁用）

以暖橙主色 #ffb347 为基准：
- 默认按钮（普通级，如「取消」「关闭」）：背景 #2a2a2a，边框 #3a3a3a，文字 #e0e0e0
  - hover：背景 #333333，边框 #4a4a4a
  - active：背景 #3d3d3d
  - disabled：背景 #222222，边框 #2e2e2e，文字 #666666，鼠标 cursor: not-allowed
- 主按钮（推荐级，如「导入」「删除所有」）：背景 #ffb347，边框 #ff9e1a，文字 #121212（深色字保证对比度）
  - hover：背景 #ffc370，边框 #ffb347
  - active：背景 #ffa325
  - disabled：背景 #5a4825，边框 #6a5835，文字 #8a7855
- 危险按钮（「我已确认删除」类）：背景 #ff6b4a，边框 #ff5533，文字 #ffffff
  - hover：背景 #ff8468
  - active：背景 #ff5533
  - disabled：背景 #5a3025，边框 #6a4035，文字 #8a7065
- 待删按钮（顶部栏）：N>0 时使用危险按钮色；N=0 时降级为普通按钮 disabled 色。

输入框样式（所有单行输入、路径框）：
- 默认：背景 #141414，边框 #2e2e2e，文字 #e0e0e0
- focus：边框 #ffb347（2px，其他状态1px），内部 1px 描边 #4a3a20
- error：边框 #ff6b4a，内部 1px #4a2a20，右侧显示错误图标+tooltip

1.5 图标规范（16B 填充风格）

统一使用 Phosphor Icons 的 Fill 变体（填充风格）。若无版权问题则用该库 SVG；若不可则按风格重绘。
- 常规尺寸：16px（工具栏、按钮内）、14px（EXIF行前小图标）、20px（模态框大按钮前置图标）
- 颜色：默认跟随文字色（#e0e0e0 / #9a9a9a）；hover/active 时跟随父元素文字色变化；状态图标（警告/删除/保留）使用对应颜色常量：
  - 警告图标：#ffb347
  - 错误图标：#ff6b4a
  - 成功/保留图标：#4cdb8a


## 二、主界面布局

### 2.1 整体架构（从上到下，从左到右）

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 顶部栏（软件名 + 文件夹路径 + 排序 + 搜索框 + 过滤 + 导入 + 发送LR + 待删）│
├──────────────────────────────────────────────────────────────────────────┤
│ 顶部进度条（细条，显示筛选进度，终局变绿）                                │
├──────────────────────────────────────────────────────────────────────────┤
│ ┌───────────────────────────────────────────────────────┬──────────────┐│
│ │                                                       │ 右侧信息面板  ││
│ │               大图预览区                             │ · 直方图      ││
│ │               （纯黑背景）                           │ · EXIF信息    ││
│ │                                                     │ · 照片状态    ││
│ └───────────────────────────────────────────────────────┴──────────────┘│
├──────────────────────────────────────────────────────────────────────────┤
│ 底部缩略图横条（横向滚动 + 高亮边框 + 多选高亮）                        │
├──────────────────────────────────────────────────────────────────────────┤
│ 底部状态栏（筛选进度 + 保留/待删计数 + 快捷键提示）                     │
├──────────────────────────────────────────────────────────────────────────┤
│ 设置入口（左侧底部，齿轮图标，浮在状态栏左端上方）                     │
└──────────────────────────────────────────────────────────────────────────┘
```

### 2.2 各区域占比与窗口约束（参考值 s=1.0）

硬约束（操作系统层面限制，不允许用户超出）：
- 最小宽度：1024 px
- 最小高度：640 px
- 不设最大尺寸，允许最大化/全屏。

区域尺寸（均为 min 尺寸，可由用户拖拽调整，见 2.3）：
- 顶部栏：固定高度 56 px（不可调整）
- 顶部进度条：4 px 高度（不可调整）
- 预览区 + 右侧面板：弹性（约剩余 70% 窗口高度）
- 右侧面板宽度：默认 260 px，最小 200 px，最大 500 px，可拖拽左边界调整
- 底部缩略图条：默认高度 120 px，最小 80 px，最大 300 px，可拖拽上边界调整
- 底部状态栏：固定高度 40 px（不可调整）
- 设置入口：浮动在左下角，覆盖在底部状态栏左端上半部分，48x48 px 点击热区（视觉图标 20x20 px，居中）

2.3 可拖拽分隔线

- 右侧面板左边界：竖向 4 px 热区，鼠标悬停变 resize-ew 光标，拖拽改变面板宽度。实时预览宽度变化，松手后持久化到工作区状态（下次启动恢复）。
- 底部缩略图条上边界：横向 4 px 热区，鼠标悬停变 resize-ns 光标，拖拽改变高度。同样持久化。
- 右侧面板折叠：按 I 键或点击面板右上角折叠图标（< 或 >）后，面板宽度自动变为 0 px，预览区自动扩张占满；再次按 I 恢复到上次记住的宽度。
- 分隔线颜色：默认完全透明（不可见，仅靠鼠标悬停光标变化提示）；拖拽中显示 1 px 实线 #ffb347 临时高亮。

2.4 响应式策略（窗口 < 阈值时自动降级）

当用户拖拽缩小窗口触发 min 约束前，自动适配：
- 宽度 < 1200 px 且 ≥ 1024 px：
  - 右侧面板默认折叠（用户手动展开仍可）。
  - 顶部栏搜索框由 260 px 宽压缩为 180 px，过长文字截断显示省略号。
  - 排序下拉、过滤图标保留；导入/待删按钮文字保留，图标保留。
- 宽度 = 1024 px（临界 min）：
  - 顶部栏仅保留：软件名 + 文件夹路径（压缩）+ 导入图标（仅图标不显示文字）+ 待删图标（仅图标+数量角标）。
  - 排序、搜索框、过滤、发送LR按钮收纳到顶部栏最右端的「⋮更多」菜单中，点击展开下拉面板访问。
- 任何尺寸下：预览区按可用空间智能缩放照片，始终保持纯黑填充空白边缘。
- 高度 < 768 px：底部缩略图条默认高度由 120 px 自动降到 80 px（但仍可手动调高）。


## 三、各区域详细规范

### 3.1 顶部栏

```
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│  咔咔  [ D:\旅行2026\08\20 ▾] [☰ 排序 ▾] [ 搜索文件名… ✕] [ 过滤] [导入] [→ LR] [ 待删(23)] [⋮] │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘
```

左起（固定顺序）：
1. 软件名：20px/700 #e0e0e0，左侧 20x20px 相机图标（#ffb347），组合点击热区 120x40 px。
2. 文件夹路径组件：
   - 图标：16px 填充文件夹图标。
   - 显示文本：完整路径。过长时左端截断（保留尾部文件名，如「…\2026\08\20」）。
   - 点击路径本身 → 下拉面板，内容：
     a. 最近打开的 10 个文件夹（按时间倒序，每条含路径+张数），单击切换工作区。
     b. 「浏览文件夹…」按钮 → 调用系统目录选择器切换工作区。
     c. 「复制完整路径」按钮（悬停提示 Ctrl+C 也可直接复制）。
   - 键盘：Ctrl+L 光标聚焦到顶部路径输入框（变为可编辑，回车确认切换，ESC 取消）。
3. 排序下拉（☰ 排序 ▾）：默认显示当前排序名，例「拍摄时间 ↑」。单击展开 9 项列表（对应 PRD 7.7 排序选项），当前项前打勾。
4. 搜索框（🔍）：
   - 占位文字「搜索文件名 / @过滤条件」。
   - 左 16px 搜索图标；右侧 × 按钮（有内容时可见，点击清空）。
   - 回车触发；即时搜索也可（输入 ≥ 2 字符后 300 ms 防抖触发过滤）。
   - 高级过滤按钮（⌕）：点击展开 3.1.1 过滤面板。
5. 导入按钮（⬇）：见 1.4 主按钮样式。未进入空工作区时始终可用。
6. 发送到 LR 按钮（→ LR）：未检测到 LR（对应 PRD 十三）时为 disabled 灰态，悬停 tooltip 提示；筛选终局前同样为半可点击状态（不触发但提示「筛选完成后可用」）。
7. 待删按钮（🗑 N）：N=0 时为普通 disabled 色；N>0 时为危险按钮样式。右侧括号内数字加粗。
8. 更多按钮 ⋮：宽度 ≥ 1024 px 且 < 1200 px 时收纳发送LR；= 1024 px 时收纳排序、搜索、过滤、发送LR四项。展开为下拉面板。

高度：56 px。内边距：左右 24 px，垂直 12 px。所有元素水平居中对齐同一行。

3.1.1 高级过滤面板（点击 ⌕ 过滤展开的弹出层）

- 弹出位置：紧贴过滤按钮正下方，右对齐。宽度 340 px，最大高度 600 px，超出部分可滚动。
- 遮罩：无（点击外部自动关闭）。
- 内容（自上而下，每项间距 12 px）：
  1. 状态 3 选 1 按钮组（全部 / 未处理 / 待删 / 已阅跳过）。
  2. 相机型号：多选下拉（从已有数据库中提取相机型号，勾选）。
  3. 镜头型号：同上。
  4. 光圈、快门、ISO、焦距：每个均为双滑块 + 左右输入框（最小组/最大组）。
  5. 拍摄日期：双日期选择器（开始/结束）+ 4 快捷按钮「今日 / 近7天 / 本月 / 上月」。
  6. 格式：多选勾选项（NEF / CR2 / ARW / JPG / PNG / HEIC / TIFF 等）。
  7. 文件丢失 / RAW+JPG 配对：三选一单选。
- 底部：「应用」主按钮 +「重置全部」链接按钮 + 当前生效条件数统计文字「共 {N} 项条件已激活」。

### 3.2 顶部进度条

- 位于顶部栏正下方，紧贴顶部栏底部。
- 高度：4 px。
- 背景：#2a2a2a。
- 填充色：默认 #ffb347；当 processed == total（筛选终局）瞬间切换为 #4cdb8a（保留色），直到用户下次修改 status 时回橙。
- 进度比例 = processed / total。
- 不显示百分比数字、不显示 hover 浮层（纯视觉进度暗示）。

### 3.3 预览区（大图）

- 背景：#0a0a0a（纯黑）。
- 照片适配方式：智能适配（默认完整显示，按 Z 切换 100% 像素级显示）。
- 竖拍照片背景：纯黑，无暗角/无装饰。
- 照片居中显示。
- 拖拽窗口接受拖入：拖入文件夹 → 触发「添加模式」导入对话框；拖入单/多张图片文件 → 若同属一个 folder_path 则切换工作区到该文件夹并自动定位到第一张拖入的照片。

3.3.1 状态覆盖层（叠加在大图上的元素）

所有元素 Z-index：底→顶依次为 照片 < 溢出警告 < 角标/状态 < 右键菜单。
- 右上角角标（可多个并存，自右向左依次排列）：
  a. 「待删」红橙标：24 px 高 × 最小 42 px 宽，背景 #ff6b4a，文字 #ffffff 12 px/600 + 内边距左右 8 px，左对齐显示文字「待删」。
  b. 「RAW+JPG」小标：18 px 高 × 60 px，背景 rgba(30,30,30,0.85)，文字 #e0e0e0 11 px/500。
  c. 「仅预览」小标（preview_only=1 或 decode_failed=1）：18 px 高，背景 rgba(255,179,71,0.2) 边框 #ffb347 1 px，文字 #ffb347 11 px/500，内容「仅内嵌预览」。
- 四角溢出警告（可开关，见设置）：
  - 高光溢出（255端比例 > 3%）：右上角 10x10 px 红色方块 + 「高光溢出」文字 12 px/500 #ff6b4a，透明度 0.8。
  - 暗部死黑（0端比例 > 3%）：左下角 10x10 px 灰色方块 + 「暗部死黑」文字 12 px/500 #9a9a9a。
- 「文件丢失」灰标（current_path 不存在时）：全屏覆盖半透明 rgba(0,0,0,0.75) + 居中显示：
  - 120x120 px 图标（带斜杠的相片图标，#ffb347 描边）。
  - 标题：「文件已丢失」20 px/600 #e0e0e0。
  - 正文：「路径：{current_path}，是否从数据库移除此记录？」14 px #9a9a9a。
  - 两个按钮：「移除丢失记录」（危险按钮样式，小号）/「稍后处理」（默认按钮样式，小号）。
- Z键 100% 放大模式：左上角显示倍率「100%」14 px/600 #e0e0e0，背景 rgba(0,0,0,0.6) 24x40 px；右下角显示当前视口位置小地图（示意缩略图+矩形表示当前显示区域，< 100x60 px）。

3.3.2 预览区右键菜单

右键点击预览区空白或照片上弹出：
1. 标记待删（Q）—— 带 Q 角标提示
2. 标记已阅跳过（E）—— 带 E 角标提示
3. 取消标记，重置未处理（U）
4. ── 分隔线
5. 顺旋转90°（R）
6. 逆旋转90°（Ctrl+R）
7. 重置旋转（Shift+R）
8. ── 分隔线
9. 强制重试RAW解码（仅当 decode_failed=1 时可见）
10. ── 分隔线
11. 文件操作 >（二级子菜单，收纳低频操作）
    - 在资源管理器中打开所在文件夹（选中该文件高亮）
    - 复制文件路径
12. 如果该照片「文件丢失」可见：「从数据库移除此记录」

### 3.4 右侧信息面板

宽度：默认 260 px。背景：#161616。左边界：1 px solid #2a2a2a。
内边距：16 px（上、下、左、右）。可折叠（按 `I` 键或右上角「<」按钮切换）。
右上角额外元素：折叠图标（<）+ 悬停显示 tooltip「折叠面板（I）」。

内容从上到下（每项垂直间距 16 px，标题与内容间距 6 px）：

**直方图**
- 标题：小字 12 px/500 #9a9a9a + 右侧小箭头 ▾（点击弹出直方图通道模式切换菜单：RGB全部 / R / G / B / Luminance，当前项打勾）。
- 画布高度：100 px，宽度撑满面板（约 228 px）。
- 数据渲染：R=#ff6b4a 半透明、G=#4cdb8a 半透明、B=#6ba8ff 半透明 三条叠加；亮度=#e0e0e0。
- 溢出端：左/右两端0或255计数>3%时，左/右边界各画一条 1 px #ff6b4a 高亮点。
- 右键菜单：与标题箭头菜单相同。

**EXIF 信息**
- 标题：同上「EXIF 信息」12 px/500 #9a9a9a。
- 每行：左侧 14x14 px 图标（相机/镜头/焦距/光圈/快门/ISO 对应 Phosphor Fill 图标）灰 #666，其后标签 12 px #666 + 冒号 + 值 13 px #e0e0e0。行间距 8 px。
  - 相机型号：例 NIKON D7100
  - 镜头型号：例 AF-S DX 18-105mm f/3.5-5.6G ED VR
  - 焦距：例 35 mm
  - 光圈：例 f/5.6
  - 快门速度：例 1/200 s
  - ISO：例 400
  - 拍摄时间：例 2026-08-23 16:38:02
  - 文件大小：例 26.4 MB
  - 文件格式：例 NEF (14-bit RAW) + RAW+JPG 标
  - 原始文件名：DSC_0342.NEF
- 值不存在 / EXIF读失败：显示「—」灰 #666，不报红。

**照片状态**
- 标题：「照片状态」12 px #9a9a9a。
- 当前状态大标签：
  - 未处理：灰标签 32x80 px，背景 #2a2a2a 文字 #9a9a9a 14 px/600。
  - 待删：危险色标签，背景 rgba(255,107,74,0.15) 文字 #ff6b4a 14 px/600 + 边框 1 px #ff6b4a33。
  - 已阅跳过：保留色标签，背景 rgba(76,219,138,0.12) 文字 #4cdb8a 14 px/600 + 边框 1 px #4cdb8a33。
- 辅助行（12 px #666）：
  - 若标记时间存在：「标记于 {marked_delete_time/review_time}」。
  - 若 rotation_override != 0：「已旋转 {90/180/270}°」，按钮「重置旋转 Shift+R」（小链接样式）。
  - 若 decode_failed=1：橙字警告「RAW解码失败，当前为内嵌预览」+ 右侧小按钮「重试」。
  - 若 preview_only=1：橙字「格式暂不支持完整解码」。

### 3.5 底部缩略图横条

高度：默认 120 px（可拖拽调整 80-300 px，见 2.3）。
背景：#141414。上边框：1 px solid #262626。
内边距：上下 12 px，左右 20 px。

缩略图尺寸与间隔（按默认 120 px 高度时）：
- 单张外框：110 x 76 px。
- 内含缩略图画布：100 x 66 px（居中，上下各 5 px），背景 #0a0a0a。
- 缩略图间隔：12 px。

状态样式：
1. 当前显示的照片（预览区中那张）：外框 3 px solid #ffb347，其余不加粗。
2. 批量选中的照片（非当前显示但 Ctrl+A/Shift 选中的）：外框 2 px solid #ffb347，左上角内部叠加 14x14 px 复选框（#ffb347 勾中）。若同时是当前显示，则以 3 px 外框为主，复选框仍显示。
3. 待删：右上角叠「待删」角标（同 3.3.1 a，缩略图版本字号更小 10 px/尺寸 20 x 34 px）。
4. 已阅跳过：无角标、无高亮，缩略图饱和度降低 15%（弱暗示，用户可以选择在设置中关闭此淡化）。
5. 未处理：无标记，正常显示。
6. 文件丢失：缩略图画布区域整体蒙灰 60% + 中心 20x20 px 丢失图标（Phosphor image-broken fill）灰 #9a9a9a。
7. RAW+JPG 配对：缩略图画布右下角叠 10 px 高小字标「R+J」，白色文字+黑底半透明。
8. 仅预览 / 解码失败：缩略图画布左下角 1 px 黄边小标 10 px「预览」。
9. 加载中 / 缓存未生成：显示纯灰占位 #2a2a2a + 中心 Spinner 14 px 环形（动画周期 1.2 s 线色 #ffb347）。

交互：
- 左键单击：切换当前显示到该张（等同于 →/← 多次）。
- Ctrl+单击 / Shift+单击 / Ctrl+A：见 PRD 7.9 多选机制。
- 鼠标滚轮（焦点在缩略图条时）：横向滚动。
- 滚动条：右侧 6 px 宽滚动条，hover 时变 8 px，thumb #3a3a3a，track 透明。
- 拖拽移动照片顺序：V1.0 不允许。拖拽滚动条允许。
- 右键单张缩略图：弹出同 3.3.2 预览区右键菜单相同内容 + 新增一项「将排序锚点定于此」（用于 Shift 范围选）。

### 3.6 底部状态栏

### 3.7 设置入口

- 点击热区：48 x 40 px（与状态栏等高，宽48）。
- 图标：20 x 20 px Phosphor gear-six fill，色 #9a9a9a；hover 变 #e0e0e0；active 变 #ffb347。

- 右键：无菜单，为将来 V1.1 扩展保留。


## 四、交互反馈

### 4.1 删除操作（Q）

- 反馈：**仅角标**。照片右上角出现 "待删" 标签（红橙色背景，白色文字，见 3.3.1a）。
- 无闪框、无音效。
- 角标持续显示，直到照片被恢复或最终删除。
- 同步：底部缩略图条的对应缩略图同样显示角标。状态栏待删计数 +1 + 对应文字闪烁 1 秒。
- 自动跳转下一张。已在最后一张时：不再跳，状态栏瞬时提示「已是最后一张」（见 4.5.1）。若开启「Q 到末尾循环」设置项（默认关闭），则跳回第 1 张。

### 4.2 跳过操作（E）

- 反馈：**无视觉反馈**。无角标、无闪框。
- 仅状态栏计数 +1，「已阅」文字短暂高亮 0.6 秒。缩略图饱和度降低 15%（可设置关闭）。
- 自动跳转下一张。

### 4.3 取消标记（U）

- 反馈：状态标签变更。若是当前照片「待删」→ 取消后「待删」角标立即淡出消失（200 ms）。
- 状态栏计数：保留数 +1、待删/已阅 -1，保持一致。
- 不自动跳转，停留在当前张。

### 4.4 批量操作

- 触发（Ctrl+Q / Ctrl+E / Ctrl+U 或右键批量菜单）：
  - 操作前浮层提示：屏幕居中弹出半透明黑色 30x120 px 小卡片，显示「对 N 张照片执行：标记为待删？」「取消」与「确认执行」按钮（小按钮尺寸，150 ms 内未点确认时自动消失为"取消"，防误触）。
  - 执行中：右下角 Toast 显示进度「批量标记中… {done}/{total}」（瞬间完成无进度；N>100 才显示进度条）。
  - 完成：Toast「已对 N 张标记为 X，耗时 {t} ms」3 秒后消失。

### 4.5 撤销 / 重做（Ctrl+Z / Ctrl+Y）

- 撤销：
  - 成功：右上角瞬时小 Toast（<120x32 px）「已撤销：{操作名}」，1.5 秒消失，无按钮。
  - 失败（栈空）：同样 Toast 灰字「无可撤销的操作」。
- 重做：成功 Toast「已重做：{操作名}」。失败同上。
- 状态变化同步刷新角标、状态栏计数、缩略图条样式。

### 4.6 Z 键放大

- 切换式：按 Z 进入 100% 像素级显示，再按 Z 或 ESC 回到适配窗口。
- 切换动画：瞬切（< 50 ms），无过渡动画。
- 进入放大：左上角显示倍率标签「100%」，右下角显示视口小地图（预览缩略图 + 当前视口实心矩形，其余半透明遮罩，可在小地图上点击跳转位置）。
- 放大后拖拽：按住空格或按住鼠标左键拖拽画面平移，光标变为 grab（按住时 grabbing）。拖拽过程中画布不重绘直方图、不更新右侧面板信息，直到松手后重算。
- 信息面板同步：照片状态下方显示当前缩放倍率文字「100%（视口解码中 / 已用 RAW / 已用内嵌 JPG）」。

### 4.7 旋转（R / Ctrl+R / Shift+R）

- 操作后：预览图瞬切旋转显示（0ms 动画，通过旋转变换矩阵）。缩略图条中对应缩略图同步旋转。
- Toast：「已顺时针旋转 90°」/「已重置为 EXIF 方向」1.5 秒消失。
- 右侧面板照片状态：显示「已旋转 {90/180/270}°」+ 小链接按钮「重置」。

### 4.8 照片切换

- 按 ← / → / Space / A / D / Home / End 切换：
  - 切换动画：无动画，瞬切（< 100 ms）。
  - 缩略图高亮同步移动：当前张边框由 3 px #ffb347 标记，滚动条自动让当前张居中显示（若已在视口内则不滚动）。
- 4.8.1 跳转边界行为：
  - 在第一张按「上一张」：停止跳，底部状态栏弹出瞬时提示「已是第一张」（2 秒，#666666 文字，Toast 形式不抢焦点）。
  - 在最后一张按「下一张」：同上，「已是最后一张」。
  - Home / End：直接跳到端点，Toast 显示「已跳到第 1 张 / 最后第 {total} 张」。
- 4.8.2 数字跳片：
  - 用户输入 0-9，顶部栏右上角透明输入浮层显示当前输入的数字串（例：「123_」），2 秒未输入新数字自动取消；回车确认跳转；ESC 取消。

### 4.9 通用 Toast / 瞬时提示规范

所有不属于模态框的轻量反馈，统一 Toast 样式：
- 位置：屏幕右上角，堆叠展示（最新在下排最上，最多同时 3 条，超出则覆盖最旧）。
- 尺寸：最小 200x40 px，最大 480x80 px，文字超出多行。
- 样式：背景 rgba(30,30,30,0.95)，1 px #3a3a3a 边框，内边距 12x16 px，文字 14 px #e0e0e0。
- 四级类型（仅左侧色条区分，不加图标除非严重）：
  - 默认 INFO：左侧 3 px 竖条 #ffb347（暖橙）。
  - SUCCESS：左侧 3 px 竖条 #4cdb8a（绿）+ 左侧打勾图标。
  - WARNING：左侧 3 px 竖条 #ffb347 + 警告图标（黄橙）。
  - ERROR：左侧 3 px 竖条 #ff6b4a + 错误图标（红橙）。
- 关闭方式：
  - INFO/SUCCESS：显示后 3 秒自动消失，hover 时延迟关闭（可手动点右上角 ×）。
  - WARNING/ERROR：显示 8 秒或手动关闭；严重 ERROR 永久显示直到关闭（例：数据库写入失败）。
- 操作按钮：ERROR 级别 Toast 支持最多 1 个主操作按钮（例：「查看失败列表」「打开日志文件夹」）。


## 五、窗口规范

### 5.1 导入对话框

- 样式：居中大弹窗（11A）。
- 固定尺寸：窗口宽 = min(屏幕宽 × 0.75, 1280 px)；高 = min(屏幕高 × 0.75, 860 px)。
- 背景遮罩：rgba(0,0,0,0.7) + blur(6 px)。
- 顶部 Tab 切换（导入模式选择）：左上「复制模式（从存储卡）」「添加模式（从硬盘）」两个 Tab 按钮（选中底部 3 px #ffb347 下划条）。用户在从导入按钮触发时默认根据上下文自动选 Tab（如从自动检测存储卡→复制；从拖入文件夹→添加），可手动切。

布局（从上到下，从上至下编号）：
1. 标题栏：
   - 标题「导入照片」20 px/700。
   - 关闭按钮（×）右上角 24x24 px 图标按钮，hover #ff6b4a。
2. 模式配置条（双栏并排，Tab 切换时内容不同）：
   - **复制模式**（左列→右列）：
     a. 源路径框：左侧标签「源路径」+ 路径输入框 +「浏览」按钮 +「检测到可移动磁盘：E:\ (NIKON D7100, N张)」自动下拉（若有）。
     b. 目标目录框：「目标目录」+ 路径输入框 +「浏览」按钮；下方子目录组织方式单选组：保持原结构/按日期/平铺（见PRD 6.1.2）。
     c. 右侧「选项」：开关组：递归扫描子文件夹（开）、去重扫描（开）、导入后清空存储卡（关）（仅源为移动盘可用）。
   - **添加模式**（简化）：
     a. 源路径框 + 递归开关（开）+ 去重开关（开）。
     b. 目标目录、清空存储卡、子目录组织三项：全部灰显隐藏。
3. 统计条（一行）：左「源共找到 N 张，已存在 Y 张，将导入 X 张，RAW+JPG {M} 组」右「预计大小：{size}」。
4. 文件列表（网格视图 12C，占最大空间弹性高度）：
   - 顶部工具栏：排序下拉（拍摄时间/文件名/大小）、筛选切换「全部 / 仅待导入 / 仅已存在」、视图缩放滑条（缩略图大小 S/M/L）、全选/反选。
   - 网格：
     - 每行张数动态计算：每行张数 = floor((对话框可用宽度 - 左右边距) / (缩略图宽度 + 间距))，最少 4 张，最多 10 张，随视图缩放滑条动态调整。
     - 每张 140x140 px 外框，缩略图 128x96 居中，状态覆盖层规则同 3.5：
       - 待导入：勾选框左上角默认勾选（开）。
       - 已存在：整体 40% 灰度，左上勾选框默认（关）不勾选，底部灰色文字「已存在，跳过」；添加模式下勾选框 disabled（禁止强制导入，tooltip 说明「添加模式下不允许强制导入已存在项」）。
       - 去重扫描中：缩略图显示半透明遮罩 + Spinner「比对中…」。
       - 丢失/损坏：缩略图灰 + 丢失图标 + 底部文字「无法读取」。
     - 悬停效果：外框亮边框 1 px #ffb347；不缩放缩略图。
     - 单张勾选框：允许用户手动勾选/取消（添加模式的已存在项除外）。
   - 空状态：源路径为空或路径不存在时，画布中央显示占位「请选择源路径」图标 + 文字。
5. 导入进度区（点击「导入」后才显示，替代底部按钮高度）：进度条 + 当前文件名 + 速率 MB/s + 取消按钮（见 PRD 6.6 格式）。
   - 导入完成后进度区自动切换为「完成报告面板」：
     a. 成功 {X} 张（绿字 #4cdb8a）/ 已存在跳过 {Y} 张（灰 #9a9a9a）/ 失败 {Z} 张（红字 #ff6b4a）/ 路径修复 {R} 条（橙字 #ffb347）。
     b. 两个小链接按钮：「查看失败列表」「查看路径修复列表」。
     c. 失败列表展开区域（若 Z>0 默认折叠）：3 条失败预览 +「导出失败列表 .csv」链接按钮。
     d. 路径修复区域（若 R>0 默认折叠）：显示「数据库路径已更新，无需重新导入照片」辅助说明小字。
6. 底部按钮栏（固定 56 px 高）：
   - 左：「高级」（展开更多开关：RAW+JPG 配对处理、Sidecar 跟随、HEIC 提醒开关等）。
   - 右：主按钮「导入 {X} 张」（#ffb347）+ 次按钮「取消」。

### 5.2 待删框

- 样式：居中弹窗。
- 尺寸：宽 = min(屏宽 × 0.78, 1200 px)；高 = min(屏高 × 0.78, 800 px)。
- 背景遮罩 + blur 同 5.1。

布局：
1. 标题栏：
   - 标题「待删照片（N张）」20 px/700，若含 RAW+JPG 组则副标题小字「包含 {G} 组 RAW+JPG」。
   - 工具栏右侧：搜索框（按文件名过滤待删）+ 排序下拉「拍摄时间升/降 / 文件名 / 目录 / 标记时间」+ 视图缩放滑条。
   - 关闭按钮 ×（右上）。
2. 照片网格（主体弹性高度）：
   - 每行 6 张（1200 宽时）。单张外框 160x160 px，缩略图 144x108 px 居中。
   - 状态覆盖层：
     a. 左上角复选框：14x14 px，选中显示 #ffb347 填充勾。Ctrl+A / Ctrl+Shift+A 作用域为当前过滤结果。
     b. 右上角：「待删」红橙角标，RAW+JPG 组额外叠加「R+J」小标。

4. 底部按钮栏：
   - 左：「恢复选中」（主按钮样式默认色，数量 0 时 disabled）+「全部恢复」（链接式按钮红字，N=0 时 disabled 灰）。
   - 右：「关闭」（默认按钮）+「删除所有（移到回收站）」（危险按钮，红色大按钮，文字带 N 张数量）。
   - 5.2.1 删除所有二次确认弹窗（嵌套）：
     - 尺寸：480x240 px 小模态框。
     - 标题图标（左 64x64 px 红色警告三角填充图标）。
     - 正文：「即将永久删除 {N} 张照片（移入回收站，可在回收站恢复）。删除后数据库中的记录将彻底清除，无法在咔咔内撤销。是否继续？」

## 六、启动与工作区

### 6.1 启动行为（17B）

启动顺序（依次执行，任意步阻塞则进入兜底分支）：
1. 数据库完整性检查 → 通过；否则执行损坏修复流程（PRD 10.6）。
2. 检查未完成的导入续传记录 → 有则先弹出导入续传选择弹窗（见 PRD 6.7.1 交互）。
3. 检查上次崩溃位 last_crash_marker → 1 则弹出崩溃恢复弹窗（见 6.3 新增）。
4. 直接打开上次工作区：恢复 current_folder_path、current_index、所有 status 标记、排序 current_sort、过滤条件 filter_json。
5. 异常兜底：若上次路径文件夹不存在 or 路径下照片数 = 0 → 回退到空状态界面（6.2），不报错不弹窗。

6.1.1 最近打开文件夹列表

顶部栏点击路径下拉（3.1）始终显示最近 10 项，显示格式：
- 首行：「 {folder_path 省略中间}」14 px #e0e0e0
- 次行小字：「{count} 张 · 最近打开 {last_open_date}」12 px #666666
支持右键某项：菜单「从最近列表移除」「清理全部最近」。
工作区关闭时该 folder_path 的 last_open_time 写入数据库。

6.1.2 多工作区策略：V1.0 不支持多窗口/多 Tab 同时浏览
- 切换文件夹 = 关闭旧工作区（自动保存全部状态）+ 打开新工作区。
- 同一时刻仅存在一个激活的筛选视图。
- 状态栏计数和顶部进度条严格对应当前激活工作区。
- V1.1+ 可通过「新建窗口」菜单项启动第二个 kaka.exe 进程间接使用多窗口（不在本版本设计内）。

6.1.3 首次启动三步引导（对应 PRD 十七）

触发条件：空白库 + 无配置。
样式：居中 560x420 px 向导弹窗。遮罩 blur 6。
通用元素：
- 顶部进度指示：三个圆点代表三步，当前步实心橙、其余空心灰。
- 右上角「跳过引导」链接式灰按钮。
- 底部：「上一步」（第一步隐藏）/「下一步」/「完成」· 两个主按钮。
Step 1 欢迎：
  - 标题「欢迎使用咔咔」。
  - 正文 4 行要点：
    1. 只做导入 + 筛选，不做后期。
    2. Q 标记待删 / E 跳过 / Z 放大 / ←→ 切换。
    3. 所有照片文件原地不动，仅记录在本地数据库。
    4. 删除照片仅移入回收站，可恢复。
  - 左下：「查看快捷键完整列表」小链接（弹出滚动列表）。
Step 2 基础设置：
  - 默认目标目录（复制模式）：路径框 +「浏览」。
  - 检测存储卡自动弹出导入窗口：开关（开）默认开。
Step 3 选择导入：
  - 两个大卡片按钮并排（240x140 px，卡片边框 1 px #3a3a3a，hover #ffb347）：
    卡片 A 左：图标（SD 卡）+ 标题「从存储卡导入」+ 说明「推荐新拍摄的照片，将照片复制到电脑」。
    卡片 B 右：图标（文件夹）+ 标题「从硬盘文件夹添加」+ 说明「仅索引，不移动或复制原文件」。
  - 也可点下方小字「稍后手动导入」→ 进入空状态。

### 6.2 空状态

## 七、通用组件规范（新增）

### 7.1 加载态 / 骨架屏

- 缩略图未就绪（3.5 状态9已有）：纯灰占位 #2a2a2a + Spinner 14 px。
- 主预览图未就绪（首次切换未缓存）：整区灰 #0d0d0d，中央 Spinner 24 px，持续时间 < 300 ms 不显示动画防闪烁，>300 ms 才出现。
- 导入去重扫描：文件列表整区遮罩 + 顶部进度条 + 文字「扫描比对中… {x}/{total}」。
- 缓存重建 / 批量导出等后台长任务：屏幕右下角固定浮动任务卡（可关闭），小进度条 + 可取消按钮。

### 7.2 二次确认弹窗统一规范

用于所有破坏性操作、设置变更、删除/放弃/清空类动作：
- 尺寸：最小 420x200 px，最大 560x320 px。
- 结构：图标区（左）+ 文字区（右）+ 底部按钮。
- 图标与颜色：
  - 警告类（危险操作）：左侧 48x48 px 三角警告填充 #ff6b4a。
  - 确认类（非破坏性设置）：左侧 48x48 px 信息图标 #ffb347。
  - 成功类：绿色 #4cdb8a 打勾。
- 标题 + 正文 + 可选辅助列表（例导出失败清单 3 条预览 +「查看全部」链接）。
- 按钮：
  - 默认按钮永远是更安全的（例：取消、保留、不删除），为默认获得焦点。
  - 主按钮（执行操作）需明确文字含动作结果（例：「我已确认，删除 23 张」而非「确定」），按类型用主色/危险色。
  - 禁止用「是/否」这样的无语义二字按钮。

### 7.3 错误弹窗规范

- 与二次确认相同结构，但按钮为「复制错误信息」+「查看日志」+「关闭」。
- 最多显示堆栈 8 行，超出折叠。
- 不自动关闭，必须用户手动关闭。

### 7.4 Tooltip 统一

- 所有 icon-only 按钮（设置齿轮、关闭×、导入按钮图标模式等）必须有 tooltip。
- 延时 500 ms 出现（鼠标静止），显示时长：到鼠标移开为止或最长 5 秒。
- 样式：黑底 rgba(0,0,0,0.92) 白字 13 px，1 px #333 边，内边距 6x10 px，无圆角（硬朗直角）。


## 八、技术实现映射（仅供开发参考）


| 界面元素 | egui 实现方式 |
| :--- | :--- |
| 主窗口 DPI 感知 | 开发时以实际 egui 版本 API 为准。`per_monitor_high_dpi = true` 在较新 egui(0.20+)中已弃用或更改，通常在 `eframe::ViewportBuilder::default().with_dpi()` 或 `NativeOptions` 中配置，或依赖 winit 自动处理。此处仅作概念参考 |
| 最小窗口尺寸 | `min_window_size: Some(Vec2::new(1024.0, 640.0))` |
| 深色主题 | `egui::Style` 自定义，背景色 #1a1a1a，`override_text_style` |
| 布局 | `egui::TopBottomPanel` 顶/底 + `egui::SidePanel` 右侧 + 中间 `CentralPanel` |
| 预览图 | `egui::Image` + `egui::TextureHandle`；Z 放大后平移靠 `scroll_area` 内拖拽或矩阵变换 |
| 直方图 | `egui::Shape::mesh` / `Painter` 绘制通道填充；溢出端画线 |
| 缩略图条 | `egui::ScrollArea` + 水平 `Grid`；多选状态用 `HashMap<PhotoId, Selection>` |
| 进度条 | `egui::ProgressBar` 或自定义 4 px 细条 |
| 模态框（导入/待删/设置/二次确认） | `egui::Window` + `show_central`，加蒙版层 `CentralPanel` 绘制半透明矩形 |
| 快捷键匹配 | `ctx.input_mut(|i| i.consume_key(Modifiers::default(), Key::Q))` 等，支持 Ctrl+/ Shift+/ Alt 组合 |
| 右侧面板折叠 + 拖拽宽度 | `SidePanel` 带 `resizable(true)` + `default_width(260.0)`，开关控制 `show` |
| 照片旋转 & 适配/100% | 渲染前对 `TextureHandle` 的 UV 用变换矩阵/或对 `egui::Image` 用 `rotate()` |
| Toast 浮动层 | 自定义无描边 `Area` 固定右上角，内部 `VecDeque<Toast>` 最多 3 |
| 右键菜单 | `response.context_menu(|ui| ...)` |
| 拖入窗口 | `ctx.input(|i| i.raw.dropped_files.clone())`。实现时先判断 `path` 属性：若为目录 → 走文件夹导入（添加模式）；若为文件 → 检查后缀是否在支持列表内，命中则执行定位/标注逻辑，不在列表内则 Toast 提示「不支持的格式」 |
